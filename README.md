## 🌟 Overview

Welcome to **Scarpeys.io**, a personal portfolio and frontend learning project built around an 8-bit lofi aesthetic (`lofi.cafe` inspired). It showcases my journey as an aspiring frontend developer, featuring custom CSS animations, smooth scrolling (`Lenis`), a built-in retro Galaga arcade game, and local AI agent integration via **Scar AI & Omniroute**.

---

## 🎮 Key Features

*   **🎨 8-Bit Lofi Aesthetic**: CRT scanlines, pixel borders, and clean animated logos.
*   **🤖 Scar AI & Omniroute Integration**: Documentation and environment setup for running local AI agent workflows and terminal logs.
*   **📂 GitHub Projects**: Showcasing repos like **ScarFlow** (Pomodoro Timer), **ScarQuest** (To-do-list), and **StuBu** (Study Buddy).
*   **🎵 Spotify Playlist**: Embedded lofi playlist for coding background music.
*   **🚀 8-Bit Galaga Arcade**: A fully playable retro canvas mini-game with multi-wave formations, score tracking, lives, and high score saving.

---

## 🛠️ Tech Stack

*   **Frontend**: HTML5, Tailwind CSS v4, Google Fonts (*Press Start 2P*, *Plus Jakarta Sans*).
*   **Animation**: GSAP (GreenSock Animation Platform), Lenis Smooth Scroll.
*   **Backend**: Node.js, Express.
*   **AI**: Scar AI running locally through Omniroute.

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Scarpeys/Scarpeys.io.git
   cd Scarpeys.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the server**:
   ```bash
   npm start
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000`.
